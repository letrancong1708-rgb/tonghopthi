# EnglishTenses — Website tổng hợp 12 thì tiếng Anh

## Chạy thử trên máy
Mở file `index.html` bằng trình duyệt. Không cần cài đặt thêm.

## Đưa lên GitHub và Vercel
1. Tạo repository mới trên GitHub.
2. Tải lên 3 file: `index.html`, `style.css`, `script.js` (có thể tải cả thư mục bằng Git).
3. Vào https://vercel.com và đăng nhập bằng GitHub.
4. Chọn **Add New → Project**, import repository vừa tạo.
5. Framework Preset chọn **Other**; Build Command và Output Directory để trống mặc định.
6. Nhấn **Deploy**. Vercel sẽ cấp đường dẫn website.

## Chỉnh sửa nội dung
Mở `script.js`, tìm mảng `tenses`. Mỗi thì có công thức, cách dùng, dấu hiệu nhận biết, giải thích và ví dụ tiếng Anh kèm nghĩa tiếng Việt.
